# WebGL Fractal Generator

This project now includes a browser-based WebGL2 Mandelbrot explorer with animated shader coloring and interactive navigation.

## Run locally

Use any static file server from `FractalGenerator.UI` and open the printed URL:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Controls

- Drag: pan
- Mouse wheel: zoom
- Space: morph mode
- R: reset camera
